VRC Watch Shader Generator

Generate a digit texture (0–9) and a pre-configured VRChat/VRCOpenWatch shader to use it.

Configuration

The atlas always has 15 fixed cells: 0–9, ":", A, P, M, and a blank cell — that's what the shader expects. With this single atlas you can use ANY clock format (HH:MM:SS, HH:MM, MM:SS, or 12h with AM/PM); the format is chosen later in the "Clock Format" dropdown of the material in Unity — no need to generate a different atlas per format.

This shader doesn't change based on atlas size/font — the math is already normalized (0–1) and only requires the texture to have exactly 15 columns x 1 row (0-9, :, A, P, M, blank). Paste it into a .shader file in your Unity project, create a material, assign this shader, drag the downloaded atlas.png into "Character Atlas", and choose the format (HH:MM:SS, HH:MM, MM:SS, or 12h+AM/PM) directly in the material Inspector.
